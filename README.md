# GAV-VR-LINK Project Report

**Original title (German):**
*Integration von VANTED und GAV-VR: Virtuelle Realität als Werkzeug zur Analyse biologischer Netzwerke*

Unpublished technical project report describing the architecture and implementation of the GAV-VR-LINK add-on for bidirectional integration between [VANTED](https://cls.uni-konstanz.de/software/vanted/) and [GAV-VR](https://kops.uni-konstanz.de/entities/publication/6d49f9f7-e4c9-4703-a1d6-1012e3ad36a7).
